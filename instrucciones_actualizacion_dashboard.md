# (Obsoleto) Actualización del dashboard en claude.ai

Este documento describía una tarea programada de claude.ai que regeneraba el dashboard cada hora. Ya no se usa.

El dashboard de registros vive ahora en el software operativo (Zoho Catalyst):
- página `client/dashboard.html` (menú lateral «Dashboard»);
- datos en `functions/campus_api/dashboard.js` (se actualizan solos cada 15 minutos y con el botón «Actualizar»);
- documentación en `dashboard/README.md` y `CATALYST.md`.
